Severity:

- `high`: must be fixed before merging. Incorrect results, crashes, data loss or corruption, security vulnerabilities, broken builds, or core functionality that no longer works.
- `medium`: should be fixed. Bugs in less common paths, missing or wrong error handling, reliability problems, or maintainability problems likely to cause defects.
- `low`: minor but concrete. Misleading names, comments or documentation, small inconsistencies with the surrounding code, or gaps in tests.
